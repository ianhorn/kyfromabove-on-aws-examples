# Discovering KyFromAbove in the Cloud
### Kentucky GIS Conference 2025 - Florence Kentucky

This workshop is meant to help you discover Kentucky From Above data now hosted in the [AWS Open Data Registry](https://registry.opendata.aws/kyfromabove/).  Within the current folder are several tutorials to help you navigate how to access, leverage, analyze, and visualize orthoimagery, elevation models, and point cloud files.

The following is an organization of the workshop and tuturials:
 - Set up python/conda environment
 - Run first tutorial
    - access geopackage tile layers
    - display a map
 - set up a process to bulk download
    - find an area of list
    - list files
    - download
 - Introduction to STAC and Titiler
    - Spatiotemporal Asset Catalog
    - Titiler - mosaicking COGs
 - Run analyses on mosaicked dataset
 - Explore!
